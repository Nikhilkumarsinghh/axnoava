# Production checklist
- Replace example.com, demo email, address, brand assets and all sample details.
- Publish original, useful content and verified case studies only.
- Test responsive layouts, accessibility, reduced motion and Core Web Vitals.
- Optimise images/fonts, lazy-load non-critical media and minimise JS.
- Configure cookie consent for analytics/advertising where required.
- Review privacy, terms, refunds, tax and consumer obligations with a qualified professional.
- Use managed PostgreSQL, backups, restore tests, rate limits, admin RBAC/MFA, audit logs, monitoring and error reporting.
- Add transactional email, anti-spam/CAPTCHA and data retention/deletion flows.
- Add Razorpay webhooks, idempotency, refund handling and reconciliation before production.
- Apply for AdSense with your verified live domain and original content; approval is Google's decision.
- Test Android/iOS devices, secure token storage, offline/error states, store assets and store compliance.

- Confirm the actual AXNOVATECH domain before setting canonical metadata or DNS.
- Configure `CONTACT_TO_EMAIL` and SMTP credentials; test the enquiry and review email flows.
- Approve all public pricing and delivery claims; this build uses quote-based pricing.
- Keep only real, client-approved testimonials and accurately labelled work examples.
- Review `docs/AXNOVATECH_LAUNCH_RUNBOOK.md`; legal pages are drafts and require professional review.
- Add persistent edge rate limiting/bot protection before production; in-memory limits are not distributed.

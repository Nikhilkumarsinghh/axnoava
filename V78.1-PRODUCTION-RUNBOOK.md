## Email delivery
The contact endpoint sends messages to `nikhilkauriya04@gmail.com`. Configure the following environment variables in Render or `apps/web/.env.local`:

- `CONTACT_TO_EMAIL=nikhilkauriya04@gmail.com`
- `SMTP_HOST=smtp.gmail.com`
- `SMTP_PORT=465`
- `SMTP_USER=<verified Gmail mailbox that will send mail>`
- `SMTP_PASS=<Google App Password for that mailbox>`
- `SMTP_FROM_NAME=AXNOVATECH Website`

Use a Google App Password with 2-Step Verification enabled. Do not put secrets in Git or send them in chat. `SMTP_USER` is the sending mailbox; `CONTACT_TO_EMAIL` is the inbox receiving enquiries. Test by submitting a real enquiry from `/contact` after deployment and confirm delivery plus reply-to behaviour.

## Render deployment
`render.yaml` defines a Node web service in Singapore. To deploy, first push this repository to a Git provider Render can access, then create a Render Blueprint using this repository and `render.yaml`. Enter `SMTP_USER` and `SMTP_PASS` in Render's secret environment-variable form. The included free plan can spin down when idle; upgrade to a paid instance if always-on response time is required. The blueprint is a deployment configuration, not a completed deployment.

## Before public launch
